# 지역(동네) 검색 기획·구현 노트

> **구현 완료** 문서입니다. 왜 이렇게 만들었는지와, 다음 단계(코스 추천)로 어떻게
> 이어지는지를 적어 둡니다.

"오늘 어디 갈까?"를 **동네 단위로 먼저 고르는** 기능. 카드 하나를 고르는 게 아니라
**갈 동네를 좁힌 다음** 그 안의 카드를 보는 순서다.

```
🧭 "비 오는 날 조용히 걷기 좋은 데"
   ↓
1. 성수동   카드 4개   조용한 카페 3곳          87
2. 연남동   카드 3개   경의선숲길 산책 카드 있음  74
3. 성동구   카드 2개   실내 전시 카드            51
   ↓ (누르면)
목록·지도가 그 동네로 걸러짐
```

---

## 1. 정한 것 ✅

- **내 보드 안에서만 고른다.** 안 가 본 새 동네를 발굴해 주지 않는다. 카드가 붙어 있는
  동네만 후보다 — 추천 근거를 전부 "우리가 저장해 둔 것"으로 유지하기 위해서.
- **동 단위가 기본, 구·시·군까지 폴백.** 아래 2번 참고.
- **관련도 순 정렬.** 점수를 화면에 그대로 보여준다. 같은 점수면 1등 동네에서
  가까운 곳이 위로 올라온다("강남 쪽" 같은 검색에서 붙어 있는 동네끼리 모이게).
- **검색이 곧 필터다.** 결과를 누르면 태그 칩·달력과 같은 자리에서 같은 일을 한다
  (목록·지도가 함께 걸러진다). 별도 화면을 만들지 않았다.
- **코스 추천은 이번 범위 밖.** 지역 좁히기까지만.

## 2. 동네를 어떻게 나누나 (`src/utils/regions.js`)

새 컬럼도, 추가 수집도, 외부 API도 쓰지 않는다. 이미 저장된 `places[].address` 문자열만 판다.

1. 주소에 **지번(○○동/읍/면/리)** 이 있으면 그게 동네다 → `성수동`
2. 없으면(= 도로명주소뿐이면) **카드의 제목·메모**에 적힌 `○○동`을 빌려 쓴다.
   단, **딱 하나만 나올 때만.** 여러 개면 어느 장소의 동네인지 알 수 없어 포기한다.
   캡션 원문은 쓰지 않는다 — 길고 다른 동네가 여럿 섞여 있어 엉뚱하게 묶인다.
3. 그래도 없으면 **구·시·군 단위**로 묶는다 → `광진구`

> **왜 폴백이 필요한가**: 네이버 지역검색은 도로명주소를 주고 우리도 그걸 저장한다.
> 도로명주소에는 동 이름이 아예 없다("서울 성동구 아차산로17길 49"). 그래서 저장된
> 카드 상당수는 1번으로 동네를 못 정한다. 결과 목록에 `성수동`과 `광진구`가 나란히
> 나오는 건 버그가 아니라 이 설계의 결과다.

- 표준형: `성수동2가` → `성수동`, `역삼1동` → `역삼동`. `종로1가`·`신반포로11길` 처럼
  로/길 이름은 동네가 아니다.
- `고양시 일산동구`처럼 시 + 구가 이어지면 한 덩어리로 본다.
- 한 카드에 여러 동네의 장소가 있으면 **그 카드는 여러 동네에 같이 들어간다**
  (성수동 카페 + 왕십리 술집인 코스 게시물).

## 3. 검색은 어떻게 하나

| | 어디서 | 무엇을 |
|---|---|---|
| 1순위 | Edge Function `region-search` (Claude Haiku) | 분위기·활동까지 읽고 0~100 점수와 이유 |
| 폴백 | `src/utils/regionSearch.js` 로컬 매칭 | 동네 이름·태그·장소 이름 부분 일치 |

- 폴백은 **Supabase 미설정(localStorage 모드)** 이거나 함수 호출이 실패했을 때 자동으로
  걸린다. 이중 모드 규칙 때문에 반드시 남겨 둔다.
- AI를 못 쓴 이유는 **검색 결과 위에 그대로 띄운다** (실패를 조용히 삼키지 않는다).
- AI에는 카드 본문을 통째로 보내지 않는다 — 제목·태그·장소 이름·메모만. 동네 40곳,
  동네당 카드 8장이 상한이다.
- AI가 하나도 못 고르면 억지로 채우지 않고 "못 찾았어요"를 보여준다.

## 4. 다음 단계 — 코스 추천으로 잇기 ❓

이 기능은 코스 추천의 **앞단**으로 설계했다. 동네를 하나 고르면 그 안의 카드들이 이미
`places[].time_slots`(장소별 시간대)를 갖고 있으므로,

```
동네 고르기 → 그 동네 장소들을 점심 → 오후 → 저녁 순으로 줄 세우기 → 코스 한 줄
```

이 되면 끝이다. 남은 결정거리:

- 코스에 넣을 장소를 몇 곳으로 볼지 (3곳? 시간대마다 1곳?)
- 이동 거리를 볼지 (같은 동네 안이면 대개 걸어서 이동 가능하니 처음엔 무시해도 될 듯)
- '한 것' 카드를 코스에 섞을지 (또 가고 싶은 곳 vs 새로 갈 곳)
